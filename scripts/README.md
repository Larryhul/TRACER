# Experiment and analysis helpers

These helpers cover dataset preparation, experiment execution, runtime freezing and paired-statistics analysis. Run them from the repository root. Use [the reproduction guide](../docs/reproduction.md) for the supported initial path.

External campaign scripts require simulator installations and previously generated checkpoints. Development and extension scripts retain their experimental status; they are not the default CPU CI suite. Historical queue controls, internal meeting-report generators and archive packers are excluded from this release.
