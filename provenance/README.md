# Provenance

`source_files.csv` records copied file identities, repository-relative research origins, source SHA-256, distributed SHA-256 and portable-path changes. `assets.csv` verifies selected result tables and method graphics. `upstream.json` records the inherited MID checkout and research snapshot context.

Known original machine paths were normalized in executable defaults and table metadata. Portable source text uses LF line endings. Numerical CSV fields remain unchanged. Source hashes distinguish the original and published versions.

New repository documentation, packaging metadata, CI and the quickstart configuration were authored during publication preparation; they are not historical experiment outputs.
