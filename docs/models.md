# TRACER models

The v0.2.0 archive provides the synthetic demonstration checkpoint generated by `tracer.demo`. It contains the model state, configuration, seed and a `synthetic-demo` purpose label.

```bash
python tools/download_models.py
python -m tracer.demo --checkpoint data/external/checkpoints/tracer-synthetic-demo.pt --output outputs/demo
```

The command verifies the archive and checkpoint checksums. Loading the checkpoint skips the small demonstration training step.

[Direct archive download](https://github.com/Larryhul/TRACER/releases/download/v0.2.0/tracer-demo-checkpoint-v0.2.0.zip) · [Checksums](../provenance/model_release.json)

## Formal experiment assets

Formal response, belief-calibration and navigation checkpoints are not distributed in this release. The demo checkpoint illustrates the public CPU workflow. Published numerical records, configuration identity and formal asset requirements are indexed in [results](../results/README.md), [configurations](../configs/README.md) and the [experiment guide](reproduction.md).

The demo archive includes the repository MIT license. External dataset and simulator inputs use their providers' distribution channels.
